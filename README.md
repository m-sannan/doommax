# DoomMax

Satirical doomscrolling aggregator. One infinite vertical feed that pretends to pull from Reddit, X, Instagram, and YouTube Shorts.

Dark, fast, no mercy.

## Run it

```bash
cd doommax
npm install
npm run dev
```

Opens at http://localhost:5173

## Notes

- Uses real post excerpts from the shared HTML/links.
- Platform tints on cards.
- Shorts use local mock videos (replace with real clips).
- YouTube coming later.
